🧠 Simulator Logic

Market movement uses a small trend + sector effect + random noise model. It is a game mechanic, not a forecast.

Buy → validate cash → update cash/holding → record transaction → recalculate → render.

Sell → validate shares → add proceeds → reduce holding → record transaction → recalculate → render.

📌 Account Rules

  • Starting virtual capital: ₹1,00,00,000
  • No real money or brokerage orders
  • Short selling is not enabled
  • Prices update approximately every 5 seconds
  • State can be saved in browser localStorage
